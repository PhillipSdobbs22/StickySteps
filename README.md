# StickySteps

Floating sticky notes that follow you across apps until you're done. Free, open source, private.

## Status
🚧 Early planning — researching similar apps and designing mockups.

## Planned features
- Hotkey opens a blank note; paste anything and it floats over every app
- Smart Capture: screenshot → on-device AI finds phone numbers, emails, codes, steps
- Tap **Done** and the note goes away (history saved; passwords auto-expire)
- Mac first, iPhone to follow
